
### Coding

The loading indicator you see in the top right corner on this page is the default loading indicator of the 👜 Bag of Tricks ✨.
It is automatically activated if you <a data-astro-reload href="/library/Installation/">install astro-vtbot</a> as an astro integration.

The default icon that is displayed is the favicon of the current page.
Of course, you can tweak the look & feel of the <a data-astro-reload href="/library/LoadingIndicator/">&lt;LoadingIndicator/> component</a> to your liking.

If you want to know what happens behind the scenes, here is a rough sketch of the code that is used to display a loading indicator if you use the reusable `<LoadingIndicator/>` component or the TypeScript pendant `loading-indicator.ts`:

```javascript title="loading-indicator.js"
document.addEventListener('astro:page-load', doInit); // optional: dynamically setup the indicator
document.addEventListener('astro:before-preparation', doShow); // show the indicator
document.addEventListener('astro:before-swap', doHide); // hide the indicator
```
